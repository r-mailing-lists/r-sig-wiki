# r-sig-wiki

Setting up and managing a wiki devoted to R

Automated mbox archive. Updated daily via GitHub Actions.

## Structure

- `raw/` - Monthly .mbox files downloaded from [https://stat.ethz.ch/pipermail/r-sig-wiki/](https://stat.ethz.ch/pipermail/r-sig-wiki/)
- `processed/` - Structured JSON output from rmail-parser
- `meta.json` - List statistics
